# 樣板提示詞｜template-002 Cyber Security（SENTINEL 守衛資安）

## 1. 樣板一句話定位
以深藍黑資料信任美學打造的資安企業形象網站，用終端機儀表板 Hero、即時威脅情資與數據化案例卡片，把抽象的資安防護轉化為看得見、可驗證的信任感。

## 2. 適合產業
資訊安全服務商、資安託管（MSSP）、SOC 監控中心、雲端安全顧問、滲透測試與數位鑑識團隊、科技商務 B2B 企業、SaaS 資安產品、關鍵基礎設施防護、合規稽核顧問。

## 3. 不適合產業
餐飲酒吧、精品時尚、婚禮花藝、親子寵物、溫馨醫療診所等需要柔和、暖色或生活感氛圍的產業；亦不適合以大量全幅寫實照片敘事為主的觀光與飯店品牌。

## 4. 視覺方向
深色科技指揮中心風格。以深 navy-black 為底，搭配低透明度技術網格背景（repeating-linear-gradient）、掃描線、尖角 2px 圓角、1px 細邊框與輕微發光。整體給人冷靜、精準、可信賴的數據感，而非豪華或溫暖感。

## 5. 色彩策略
- 基底 #070b14（deep navy-black），表面 #0e1524，表層 #131d30。
- 主色電光青 #38d6ff：用於按鈕、數據、強調標題、發光效果。
- 輔色警示琥珀 #ffb454：用於標籤、序號、風險標記。
- 狀態綠 #3ddc97：用於「所有系統正常」與正常狀態。
- 文字 #e9f3fc，次要文字 #93a7c0，微弱文字 #5f7593。

## 6. 版型策略
左右分割的非全螢幕 Hero，左側文案與四組即時數據讀數，右側 CSS 打造的資安主控台。內容節奏採「統計數字 → 威脅情資 → 六大解決方案 → 數據案例 → 客戶評價 → FAQ → CTA」。所有卡片採資料密集型 bento 風格，附角括號裝飾與 monospace 標籤。

## 7. Hero Pattern
dashboard-terminal-hero：非全幅照片背景。左側為大標題、副文案、兩顆按鈕與四組數據讀數（99.99% 防護率 / 24/7 監控 / 0 事件 / 38 國據點）；右側為 CSS 繪製的 security console，包含視窗標題列紅黃綠圓點、發光城市／世界地圖圖片疊加網格、單色監控日誌與掃描線動畫。

## 8. Navigation Pattern
left-logo-right-pill-nav：左側為 SENTINEL 字標搭配盾牌圖示，右側為膠囊狀（border-radius 999px）導覽連結，hover 時亮起青色，另有一顆實心青色「預約 Demo」按鈕。手機版收合為右側抽屜。

## 9. Content Rhythm
首頁依序為：dashboard Hero → 信任標準條 → 即時威脅情資 → 六大解決方案（3×2）→ 數據案例卡片 → 客戶評價 → FAQ 手風琴 → 最終 CTA。內頁共用相同設計語言與 page-hero（網格背景＋右側裝飾圖）。

## 10. 圖片風格要求
僅使用科技／資安／AI 類型的 Unsplash 圖片，色調偏暗、帶有資料流、電路、程式碼、城市科技感。所有圖片套用統一的青色網格與掃描線偽元素疊層，並以 filter 微調亮度與色相，維持一致的終端機視覺。

## 11. 圖片數量要求
全站至少 25 張圖片引用，分散於首頁、關於我們、解決方案、方案詳情、成功案例、客戶評價、常見問題、預約 Demo、導入流程、資安洞察、文章詳情與聯絡我們，每張具備描述性 alt。

## 12. 12 頁內容定位
index 首頁（終端機 Hero 與完整轉換路徑）；about 公司介紹、團隊、認證與里程碑；services 六大解決方案總覽與比較表；service-detail 企業資安託管詳情；portfolio 數據化成功案例；reviews 客戶評價與滿意度；faq 分類常見問題；booking 預約 Demo 表單；process 六階段導入流程；blog 資安洞察文章列表；blog-detail 含 Article Schema 的文章詳情；contact 聯絡資訊、表單與地圖。

## 13. SEO 關鍵字策略
每頁具備繁體中文 title、60–160 字 description、canonical、OG 標題／描述／圖片，以及 Organization 或 Article JSON-LD。主力關鍵字包含：資安、資訊安全、資安託管、端點防護、威脅情資、事件應變、滲透測試、零信任、雲端安全，並自然分布於標題與內文。

## 14. CTA 策略
Hero 內嵌實心「預約 Demo」按鈕，搭配頁面底部固定 sticky CTA 橫幅。各章節結尾以 callout 面板引導預約或聯絡。按鈕使用 monospace 字體與青色發光，維持資料感一致性。

## 15. RWD 規則
桌機 4 欄數據卡、3 欄方案與案例；平板最多 2 欄；手機全數單欄。Header 在窄螢幕切換為右側抽屜，按鈕好點，字級不低於 12px，圖片不破版。

## 16. 可替換內容
品牌名稱 SENTINEL 守衛資安、聯絡電話與信箱、所有統計數字、客戶案例數據、團隊成員、認證名稱、文章標籤與圖片來源皆可替換為客戶實際資料。

## 17. 禁止事項
禁止簡體字、禁止中英混雜（專有名詞除外）、禁止「建置中」或空殼內容、禁止抄襲其他樣板版面、禁止使用非科技／資安／AI 類別圖片、禁止 generator 批次產生頁面、禁止破壞 file:// 相容性。

## 18. 與相似樣板的差異說明
本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。
與 template-006 AI SaaS 相比，本樣板以資安數據信任與威脅情資為核心，使用深色終端機主控台與網格掃描線，而非漸層 Bento 新創感；與 template-023 Coworking Space 相比，本樣板為深色數據導向且資訊密集，而非白灰開放空間的寫實感。Hero、導覽、內容節奏、Image Strategy、CTA、案例與頁尾布局皆有明顯區隔。
