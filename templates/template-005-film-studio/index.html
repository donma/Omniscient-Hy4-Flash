PRODUCTION / FRAME 003

五個階段，
把想法拍成畫面

從第一次溝通到最終交付，每個環節都有清楚節奏，讓創意與執行保持一致。

01 / PRE

前期溝通

釐清品牌核心、目標受眾與溝通目的，確立影像的基調與方向。

02 / SCRIPT

腳本鏡頭

撰寫腳本、繪製分鏡與拍攝清單，讓每一顆鏡頭都有存在的理由。

03 / SHOOT

拍攝執行

專業團隊與器材進場，掌握光線、構圖與節奏，留住最真實的瞬間。

04 / POST

後製調光

剪輯、配樂、音效與調光，建立統一的電影感色彩與情緒。

05 / DELIVER

交付

依不同平台輸出格式，提供完整RAW檔與社群剪輯版本。

ABOUT US / FRAME 004

我們相信，
好的影像會被記住

REFRAME 成立於 2016 年，由一群熱愛電影與攝影的創作者組成。我們把每一次拍攝都當成一部小型電影，從腳本到調光，堅持到最後一格。

不只是拍得漂亮，而是拍得有意義。透過重新構框，我們讓尋常的場景說出不尋常的故事。
