# Prompt — T007 Jazz Club「BLUE NOTE 藍調俱樂部」

## 1. 樣板一句話定位
一間藏在台北地下室的復古爵士酒吧：黑膠、琥珀燈光、現場三重奏，與一屋子願意慢下來的人。

## 2. 適合產業
爵士酒吧、Live House、現場音樂餐廳、餐酒館、黑膠主題空間、小型表演場地、附設甜點的音樂俱樂部。

## 3. 不適合產業
需要明亮簡約感的品牌（如診所、幼教、清潔用品）、強調高速與科技感的 SaaS、走極簡精品路線的時尚品牌。本樣板的油膩煙霧感與復古字體不適合這些情境。

## 4. 視覺方向
復古爵士、類比黑膠質感。深棕黑底搭配陳年琥珀、奶油白與褪色磚紅。大量黑膠圓形、art-deco 放射光芒、底片顆粒、撕紙邊緣、「演出中」霓虹小燈牌。手寫感與印刷感並存，刻意保留不完美的復古觸覺。

## 5. 色彩策略
- 主色 深棕黑 `#140f0a`：頁面與 Hero 基底。
- 強調色 陳年琥珀 `#e0a341`：標題、按鈕、光芒、選取狀態。
- 內文色 奶油白 `#efe2c8`：主要文字，確保深色底對比充足。
- 點綴色 褪色磚紅 `#8c3a2b`：日期盒、訂位盒、票根、跑馬燈。
- 照片統一套用 sepia + 對比 + 亮度微降的復古濾鏡。

## 6. 版型策略
首頁採「黑膠舞台 Hero → 演出時間軸 → 聆聽區 → 空間照片 → 菜單 → 顧客評價 → FAQ → 票根 CTA」的節奏，不同於一般三卡片公版。12 頁共用同一套字體、導覽、卡片、CTA 與 Footer；各子頁以 page-hero 開始，維持相同設計語言。

## 7. Hero Pattern
vinyl-stage-atmosphere-hero：左側一個 CSS 旋轉黑膠（repeating-radial-gradient 凹槽、磚紅標籤、主軸孔、反光）疊加 art-deco 光芒，前方是 Limelight 復古字標「BLUE NOTE」；右側「演出中」小燈牌、serif 大標「今晚，聽點真的。」、說明與「查看節目表 →」按鈕。底部磚紅跑馬燈「LIVE JAZZ · EVERY NIGHT · SINCE 1998」。刻意非置中，與 T001 的置中沉浸式 Hero 不同。

## 8. Navigation Pattern
retro-top-nav：頂部細雙線、左側復古字標與黑膠小圖、小寫 wide-tracking 選單、右側磚紅「訂位」盒。手機版漢堡置於左側，抽屜由左滑入，展開後選單清楚可讀且不遮蓋 Logo。

## 9. Content Rhythm
lineup-listen-schedule-booking：先以演出陣容建立期待，接著用引言與播放紐塑造氛圍，再以空間與菜單補足體驗，最後導向票根訂位。內頁依功能延伸至演出詳情、流程、週記與聯絡。

## 10. 圖片風格要求
所有圖片套用琥珀 sepia、略降亮度與提高對比的復古濾鏡，並疊加 noise 顆粒。偏愛舞台、樂手、薩克斯風、吧台、黑膠、暖光座位等題材。每張需有繁體中文 alt。

## 11. 圖片數量要求
全站至少 25 張圖片素材，分散於首頁、空間、海報、blog、文章的空間與細節。此樣板實際使用 38 個 img 參考、15 個以上不同 Unsplash 圖片 ID。

## 12. 12 頁內容定位
index 首頁；about 品牌故事與沿革；services 本週節目表（時間軸）；service-detail 單場演出詳情（Event schema）；portfolio 活動海報牆；reviews 顧客評價；faq 常見問題；booking 訂位購票表單；process 訂位流程；blog 爵士週記；blog-detail 文章內容（Article schema）；contact 聯絡與交通。

## 13. SEO 關鍵字策略
核心字：爵士酒吧、現場爵士、台北爵士、黑膠、Live House、節目表、訂位。每頁標題、description、canonical、OG 完整；店家頁 LocalBusiness、文章頁 Article、活動頁 Event、常見問題頁 FAQPage 結構化資料。

## 14. CTA 策略
ticket-stub-cta：以票根造型（打孔與虛線撕口、磚紅票根）呈現「訂位入場 →」，搭配票價 $480 與日期資訊。不同於簡單按鈕，具有強烈的收藏與入場隱喻。

## 15. RWD 規則
桌機 2–4 欄、平板最多 2 欄、手機全單欄。Hero 兩欄在平板轉為單欄並置中；黑膠尺寸隨螢幕縮放；漢堡與抽屜在窄螢幕出現；按鈕好點、字級不低於 12px。

## 16. 可替換內容
品牌名 BLUE NOTE、地址電話、票價、演出陣容、樂手介紹、菜單品項、甜點內容、部落格文章、社群連結、Google Map 嵌入位置皆可替換為客戶資料。

## 17. 禁止事項
禁止簡體字；禁止使用 generator 批次產生頁面；禁止與 T001 一樣的置中細金高級感；禁止只換色換圖的假冒差異；禁止出現「建置中 / Coming Soon / 內容待補」；禁止圖文不符或缺少 alt。

## 18. 與相似樣板的差異說明
不同於 template-001 Luxury Bar 的細金、置中、低光源精品酒吧感，本樣板採復古暖琥珀、黑膠圓形、art-deco 光芒、撕紙與票根，以及左側黑膠舞台 Hero 與左側手機抽屜。不同於 template-011 Music Festival 的黑紫現代舞台與海報字體，本樣板強調地下室近距離、類比黑膠與溫暖復古的爵士質感。

本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。
