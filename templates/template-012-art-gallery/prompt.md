# 樣板提示詞 — T012 Art Gallery「GALLERY NO.9 九號藝廊」

## 1. 樣板一句話定位
以固定 92px 左側導覽列為署名、以美術館說明牌為節奏的沉靜當代藝廊樣板。

## 2. 適合產業
藝廊、當代藝術空間、美術館、畫廊、藝術基金會、活動策展組織、文化展演場館、藝術商店、拍賣與收藏顧問。

## 3. 不適合產業
夜生活餐酒館、快餐餐飲、兒童樂園、重度電商、金融保險、醫療診所等需要高亮度、高轉化、密集資訊的產業；亦不適合強調活潑色彩的親子或娛樂品牌。

## 4. 視覺方向
博物館牆面般的深灰質感，大量負空間，細框線包覆影像，影像下方配置 plate-like 說明牌。整體氛圍安靜、克制、溫潤；避免使用漸層、發光、陰影濫用與高彩度裝飾。

## 5. 色彩策略
- 基礎背景：#111111（深灰）
- 表面：#1c1c1c / #232323
- 主要文字：#efede8（米白）
- 點綴：#c4704a（陶土橘，僅用於編號、狀態、細線與 hover）
- 輔助文字：#a09c95（muted）、#6e6a63（faint）
- 禁用：金色、霓虹色、漸層。

## 6. 版型策略
全站內容區以 `margin-left:92px` 偏移，讓固定左側 rail 始終可見。rail 包含旋轉垂直字標「GALLERY NO.9」、12 個極小編號導覽連結、垂直「預約參觀 →」連結，以及底部「OPEN 11:00–19:00」。桌面節目列表採 programme-list，作品目錄採 exhibition-plate-grid。

## 7. Hero Pattern
`left-rail-exhibition-hero`：在偏移內容中放置大幅當期展覽影像，外框包細線，影像內附小 plate；影像下方接一塊說明牌，含「展覽 07 / 無形之形 / 2026.04.12 — 06.30」、serif 標題、策展人短語，以及一條細體「預約參觀 →」連結。

## 8. Navigation Pattern
`vertical-left-rail`：桌面為固定左側 rail（垂直字標 + 編號索引 + 預約連結 + 營業時間）；頂部位於內容區，右側含「EN / 中文」與手機「菜單」按鈕。手機版 rail 收合為頂列 + 左側向外抽屜（drawer 從左緣滑入），內含完整 12 個選單標籤。

## 9. Content Rhythm
當期展覽 → 展覽節目索引 → 展出作品 plate 網格 → 藝術家 → 參觀資訊 → 藝廊商店 → 顧客回饋 → 常見問題 → 聯絡/CTA。

## 10. 圖片風格要求
藝術／展場類別照片為主，維持自然色調並略微降低飽和（約 saturate(.7)）與亮度，營造美術館燈光感。每張圖皆包細框，影像下方配置編號、標題、藝術家、年份的說明牌。

## 11. 圖片數量要求
全站至少 25 張圖片引用，分散於首頁、節目、作品、詳情、Blog、聯絡等頁面；每張皆須有繁體中文 alt。

## 12. 12 頁內容定位
- index.html 首頁：當期展覽 Hero + 節目 + 作品 + 參觀 + 商店 + 回饋 + CTA
- about.html 關於藝廊：品牌故事、三件事、團隊、里程碑
- services.html 展覽節目：年度展覽 programme-list、狀態標籤、延伸活動
- service-detail.html 展覽詳情：主視覺、策展論述、展出精選、參觀資訊
- portfolio.html 展出作品：展覽 plate 網格、過往展出、藝術家
- reviews.html 顧客回饋：語錄卡片、數字統計
- faq.html 常見問題：FAQ 手風琴（8 題）
- booking.html 預約參觀：假送出表單與提醒
- process.html 參觀資訊：流程、交通、展場禮儀、開放時間
- blog.html 藝廊誌：策展筆記與存檔文章
- blog-detail.html 文章內容：Article schema，完整內文與引言
- contact.html 聯絡我們：資訊列、地圖、聯絡表單

## 13. SEO 關鍵字策略
以「九號藝廊、GALLERY NO.9、當代藝術、台北藝廊、展覽、策展、藝術家、博覽會、無形之形、預約參觀」為核心；每頁 title / description / canonical / OG 齊備，內頁含 LocalBusiness、ArtGallery、ExhibitionEvent、Article、FAQPage 等 JSON-LD。

## 14. CTA 策略
`rail-anchored-visit-link`：固定的「預約參觀 →」垂直連結附著於左側 rail，並在每個展覽、章節尾聲重複出現細體版本，安靜而一致。

## 15. RWD 規則
桌機 3–4 欄 plate 網格；平板最多 2 欄；手機全部單欄。≤900px 時左側 rail 隱藏，改為頂列 + 左側抽屜；內容 margin-left 歸零。圖片不破版、字級不低於 12px、按鈕好點擊。

## 16. 可替換內容
品牌名稱、展覽名稱與日期、藝術家名單、策展論述、地址電話、營業時間、相片、社群連結、表單欄位與 SEO 文字皆可替換。

## 17. 禁止事項
本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。禁止使用金色、霓虹、漸層；禁止簡體字；禁止 generator 批次產生；禁止/building中或空白頁；禁止遮擋左側導覽或讓手機抽屜覆蓋品牌標誌。

## 18. 與相似樣板的差異說明
不同於 template-005 Film Studio 的作品牆與 template-010 Architecture 的案例索引：本樣板以固定左側垂直導覽為核心識別，並以美術館說明牌（plate）作為影像呈現語言，搭配展覽狀態標籤與 rail 錨定預約連結，形成獨特的「博物館導覽」體驗。
