# 樣板提示文件 — template-016-flower-wedding（BLOOM 花綻婚禮）

## 1. 樣板一句話定位
以米白浪漫花藝與手寫字美學為核心，為花藝婚禮與創意設計品牌打造一個以作品牆為主視覺、以「檔期諮詢」為轉換起點的柔美浪漫形象網站。

## 2. 適合產業
花藝婚禮、婚禮規劃、婚禮顧問、新娘捧花客製、花店、婚紗攝影、婚禮佈置、創意設計工作室、婚宴場地、花藝教學。

## 3. 不適合產業
需要深色科技感或數據儀表板的 SaaS 與資安產品；強調高對比力量感的健身或汽車品牌；需要大量即時交易與規格比較的電商；嚴肅醫療與金融機構。

## 4. 視覺方向
Cream romantic。以米白 #fcf8f4 為底、淺玫瑰表面 #f6ebe6，搭配灰玫瑰 #c98a92 與鼠尾草綠 #9aae94 雙強調色，深梅紫 #4a3a42 為文字。Great Vibes 手寫體只用在 "Bloom"、"love" 等少量字詞；Cormorant Garamond 襯線作為標題；Noto Sans TC Light 作為內文。大量圓角、植物線稿、柔和漸層與留白，整體輕盈浪漫。明確禁止深色、單色黑白與冷調精品感。

## 5. 色彩策略
- 背景：#fcf8f4（主）、#f9f2ed（次）、#f6ebe6（卡片表面）
- 文字：深梅紫 #4a3a42（內文）、#8a7580（次要）
- 強調色：灰玫瑰 #c98a92 / #b8747e（手寫字、按鈕、線段）、鼠尾草綠 #9aae94（次要點綴）
- 軟陰影：rgba(120,86,96,.10)
- 照片統一套用柔和暖色濾鏡（saturate .92 / sepia .06 / brightness 1.01），hover 時還原自然色澤。禁用高對比冷調與黑白濾鏡。

## 6. 版型策略
首頁為浪漫花藝拼貼 Hero → 花藝理念 → 作品牆 Masonry → 方案手写字卡片 → 真實婚禮故事 → 花藝師介紹 → 新人回饋引言 → 花藝日記 → 柔美諮詢帶 → 手寫字 Footer。內頁沿用相同字體、色階、圓角卡片、導覽與 CTA，絕不切換成一般 Bootstrap 版型。

## 7. Hero Pattern
romantic-floral-masonry-hero：4 張不同高度的花藝婚禮照片以不規則圓角、拱形與錯落高度的藝術拼貼排列於右側，左側覆蓋半透明奶油色圓角面板，面板內含 Great Vibes "Bloom"、serif 標題「把愛，綻放成永遠。」、簡介與手寫字「檔期諮詢 →」。照片上漂浮手寫字 "love"，並點綴植物線稿。平板與手機改為照片網格堆疊，面板置於下方。

## 8. Navigation Pattern
centered-script-nav：首行採「左側小字標註 / 中央手寫字 Bloom 字標 / 右側諮詢檔期」的極疏朗配置；第二行為 12 個繁體選單標籤以小號 Cormorant Garamond 置中排列。淺底深字，hover 與 active 以灰玫瑰底線標示。手機版漢堡固定右側，12 個完整標籤收於右側 drawer。

## 9. Content Rhythm
花藝 Hero → 理念與數據 → 作品牆 → 方案卡片 → 真實婚禮故事 → 花藝師 → 新人回饋 → 花藝日記 → 柔美諮詢帶。以「看見美 → 相信自己也能擁有」為轉換路徑。

## 10. 圖片風格要求
婚禮花藝、捧花、拱門、桌花、新人互動與柔光會場。照片需明亮、帶奶油色調與柔和景深；避免陰暗、銳利高對比與冷色調。所有圖片套用統一柔光暖色濾鏡，hover 時短暫還原自然色。

## 11. 圖片數量要求
全站至少 25 張圖片引用（含不同頁面重複使用），每張皆須有意義的繁體中文 alt，集中使用 IMAGE-CATALOG 的花藝／婚禮類別照片 ID，並記錄於 assets/img/image-sources.md。本樣板實際使用 75 張引用。

## 12. 12 頁內容定位
index 首頁（花藝 Hero 與作品牆）、about 關於我們（理念、團隊與里程碑）、services 婚禮服務（三大服務與細節）、service-detail 方案詳情（花藝佈置方案深度說明）、portfolio 作品案例（完整 Masonry 作品牆與風格分類）、reviews 新人回饋（推薦語與婚禮故事）、faq 常見問題（手風琴）、booking 檔期諮詢（表單假送出）、process 合作流程（六階段時程）、blog 花藝日記（文章列表）、blog-detail 文章內容（Article schema）、contact 聯絡我們（資訊、表單與地圖）。

## 13. SEO 關鍵字策略
以「花藝婚禮、婚禮規劃、婚禮花藝、新娘捧花、米白婚禮、婚禮佈置、客製花束、婚禮顧問」為核心；每頁 title / description / canonical / OG 完整，首頁與聯絡頁使用 LocalBusiness JSON-LD，文章頁使用 Article JSON-LD placeholder。

## 14. CTA 策略
soft-script-inquiry-link：以 Great Vibes 手寫字「聊聊你的婚禮 →」貫穿全站，取代制式按鈕為主要轉換語彙；輔以灰玫瑰膠囊按鈕與頁尾柔美諮詢帶，導向 booking.html。每個內容區塊結尾都留一個手寫字連結。

## 15. RWD 規則
桌機作品牆三欄、方案與故事三欄；平板作品牆兩欄、其餘最多兩欄；手機全數單欄，漢堡置右且好點，字級不小於 12px，圖片不破版，Hero 拼貼改為網格堆疊。

## 16. 可替換內容
品牌名 BLOOM 花綻婚禮、中文名與手寫字 Bloom、聯絡電話、地址、Line / IG、方案名稱與價格、新人姓名與婚禮日期、團隊角色、文章內容與表單欄位皆可替換為客戶資料。

## 17. 禁止事項
禁止簡體字；禁止深色、黑白與冷調精品感；禁止 generator 批次產生頁面；禁止「建置中／Coming Soon／內容待補」；禁止依賴後端 API；禁止與其他樣板使用相同 Hero + 三卡片 + FAQ + CTA 的公版結構。

## 18. 與相似樣板的差異說明
不同於 template-003 精品時尚的冷調留白與 Lookbook，也不同於 template-005 Film Studio 的黑色電影作品牆；本樣板以米白浪漫花藝、拱形拼貼 Hero、手寫字導覽、CSS columns 婚禮花藝作品牆、手寫字方案卡片與植物線稿 Footer 建立獨特辨識。

本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。
