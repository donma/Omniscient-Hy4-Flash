# 樣板提示文件 — template-021-local-farm（土地刻度 小農）

## 1. 樣板一句話定位
以大地綠色的長卷軸故事，為在地小農與地方品牌打造一個用章節敘事、農夫肖像與季節作物感動訪客，並導向農場參觀預約的網站。

## 2. 適合產業
在地農場、有機農場、小農品牌、地方創生品牌、田園體驗、觀光農園、蔬菜箱配送、友善農產、生態教育農場、親子農事體驗。

## 3. 不適合產業
需要大量商品規格與即時交易的電商平台；強調科技感、冷調極簡或奢華精品的品牌；需要高度後端會員與金流串接的服務平台。

## 4. 視覺方向
Earthy story。以 #f6f4ec 米白紙感為底、#e9e6d8 表面色，搭配深農田綠 #4b6b3c 與小麥金 #c9a24b、泥土褐 #3a3529 文字。Noto Serif TC 明體作為標題（溫暖書卷氣）+ Noto Sans TC 黑體作為內文。自重視覺元素包含巨大章節編號浮水印、手繪金線、小麥／芽苗圖標、紙點紋理、溫暖相片濾鏡。禁止現代光澤型錄感。

## 5. 色彩策略
- 背景：#f6f4ec（主）、#e9e6d8（表面）、#fdfcf7（卡片）
- 主要文字：泥土褐 #3a3529
- 強調色：農田綠 #4b6b3c（按鈕、標題強調）、小麥金 #c9a24b（分隔線、編號、hover）
- 深色區塊：#3c5630 深土壤綠（visit-band、interlude 覆蓋）
- 相片統一套用 sepia + saturate + brightness 的暖大地濾鏡（.farm-img）

## 6. 版型策略
首頁為 full-width 農田 Hero → 章節 01 為什麼務農（圖文交錯）→ 章節 02 一天的開始 → 全幅引言 interlude → 章節 03 農夫肖像 → 章節 04 季節作物時刻表 → 章節 05 農場日常照片卷軸 → 顧客回饋 → FAQ → 最終參觀 CTA。內頁沿用同一字體、色階、間距、導覽與 earthy-rooted-footer，絕不切換成一般 Bootstrap 版型。

## 7. Hero Pattern
earth-green-story-hero：滿版農田風景照（photo-1500382017468 或 photo-1500937386664）加暖色漸變覆蓋。左上「土地刻度 / EST. 2012」小標，中央偏左超大明體「我們種的，不只是作物。」與土地描述，底部「向下，走進我們的故事 ↓」捲動指示器，開啟一段 LONG SCROLL 敘事。

## 8. Navigation Pattern
top-section-anchor-nav：透明覆蓋 Hero 的頁首，捲動時轉為米白 solid。Logo 含小麥／芽苗 SVG 標記。導覽連結是通往故事章節的錨點（我們的故事／農夫／作物／參觀），右側「預約參觀 →」CTA。以 JS 平滑捲動，手機版左上角為可操作的 drawer。

## 9. Content Rhythm
hero → 為什麼務農 → 一天的開始（圖＋文）→ 農夫肖像 → 季節作物 → 農場日常 → 顧客回饋 → FAQ → visit CTA。每個章節有大號編號浮水印與交錯的圖片／文字，形成連續滾動的故事，而非孤立的卡片。

## 10. 圖片風格要求
農田、山丘、溫室秧苗、新鮮蔬菜、農人肖像、田間雙手、季節作物。多數套用暖大地 sepia 濾鏡，呈現質樸誠實的紀實感；hover 時短暫提升飽和度。禁用高對比光澤的商業棚拍。

## 11. 圖片數量要求
全站至少 25 張圖片引用（本樣板實際 70+ 張），每張皆須有意義的繁體中文 alt，集中使用 IMAGE-CATALOG 的有機／農產／農場與自然類別照片 ID，並記錄於 assets/img/image-sources.md。

## 12. 12 頁內容定位
index 首頁（長卷軸故事全章節）、about 我們的故事（起源、信念、歷程、農夫）、services 季節作物（四季卡片與採收時刻表）、service-detail 作物詳情（陽光番茄五階段）、portfolio 農場日常（章節式照片卷軸）、reviews 顧客回饋（推薦語與統計）、faq 常見問題（手風琴）、booking 預約參觀（表單假送出）、process 參觀流程（六步驟時程）、blog 田間筆記（文章列表）、blog-detail 文章內容（Article schema）、contact 聯絡我們（資訊、表單與地圖示意）。

## 13. SEO 關鍵字策略
以「在地農場、小農、友善耕作、季節作物、農場參觀、採收體驗、蔬菜箱、田間筆記、地方品牌」為核心；每頁 title / description / canonical / OG 完整，首頁使用 LocalBusiness JSON-LD，文章頁使用 Article JSON-LD。

## 14. CTA 策略
scroll-story-cta：在每個故事章節結尾安置「預約農場參觀 →」按鈕與提示文字，最終以深色 visit-band 收尾，並附上地址、時間、電話。所有 CTA 導向 booking.html 或 contact.html。

## 15. RWD 規則
桌機圖文 2 欄、季節作物 4 欄、農夫 3 欄；平板最多 2 欄；手機全數單欄，左側 drawer 好點開合，字級不小於 12px，圖片不破版，章節編號浮水印按比例縮小。

## 16. 可替換內容
品牌名「土地刻度 小農」、EST 年份、地址、電話、Email、Line / IG、農夫姓名與角色、四季作物與採收月份、文章標題與內文、表單欄位、visit-band 資訊皆可替換為客戶資料。

## 17. 禁止事項
禁止簡體字；禁止現代光澤型錄感或深色調 Hero（本樣板為淺色大地）；禁止 generator 批次產生頁面；禁止「建置中／Coming Soon／內容待補」；禁止依賴後端 API；禁止與其他樣板使用相同 Hero + 三卡片 + FAQ + CTA 的公版結構。

## 18. 與相似樣板的差異說明
不同於 template-017 Organic Grocery 的商品格陳列，也不同於 template-015 Brunch Cafe 的雜誌版型；本樣板以章節編號浮水印長卷軸、農夫肖像故事、季節作物時刻表、手繪分隔線與 earthy-rooted-footer 建立獨特辨識，是一段連續滾動的農田故事。

本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。
