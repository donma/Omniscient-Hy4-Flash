# template-022-bookstore｜設計提示詞（Prompt）

> 本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。

## 1. 樣板一句話定位
一間創立於 2008 年的獨立書店「行文書店」，以暖棕紙感與書架式排版，把選書、讀書會與閱讀專欄組織成一個溫暖的知識中心，讓讀者在螢幕上也能聞到紙張的味道。

## 2. 適合產業
- 獨立書店、連鎖書店、二手書店
- 地方文化品牌、藝文空間
- 出版社、閱讀推廣組織
- 剛開始數位化的傳統書店

## 3. 不適合產業
- 講求快速轉換的電商購物車型態
- 夜生活、餐酒館、舞台演出等氛圍導向產業
- 科技 SaaS、金融、醫療等需要冷調專業感的產業
- 兒童教具、玩具零售（應改用更明亮的配色）

## 4. 視覺方向
- 整體是 LIGHT 暖色紙張基調，不是深色、不是亮白。
- 觸感紙張：以 CSS SVG feTurbulence 噪音疊加做出細微紙紋。
- 書架線條、燙金式分隔、手寫推薦小卡（marginalia）與襯線首字母（drop cap）是主要裝飾語彙。
- 書籍照片一律套用 sepia + 降低飽和度的「warm paper filter」，避免鮮艷。

## 5. 色彩策略
- 紙張底色 `#f7f2e8`、表面色 `#efe6d5`、卡片 `#fbf8f1`。
- 墨棕 `#6b4f3a` 作為主要強調與按鈕色。
- 赭紅 `#b5654a` 作為激活、標籤、引用與 hover 色。
- 深咖啡文字 `#3b2f26` 保證淺底上的高對比；次要文字 `#7a6a58`。
- 不使用亮藍、螢光、競品色；全部色彩圍繞暖棕紙感。

## 6. 版型策略
- 首頁內容節奏：知識型 Hero → 本期選書書架 → 選書專題文章 → 近期活動 → 店主推薦 → 顧客回饋 → FAQ → 來店 CTA。
- 內頁共用同一套 Header、左側 drawer、頁尾紙感 Quote 與章節樣式。
- 桌機 2–4 欄、平板最多 2 欄、手機全部單欄。

## 7. Hero Pattern
- `paper-brown-knowledge-hero`：不是大圖生活照，而是暖色紙感面板。
- 左緣有垂直書脊插畫（bookshelf-motif）：五本高低不同、颜色各異的書。
- 小標「獨立書店 · 自 2008」；大標「在書裡，遇見另一個世界。」採襯線字。
- 右側放書籍照片，覆蓋暖棕漸層；右下角有旋轉的圓形印章「好書慢慢讀」。
- CTA 為「今日選書 →」連結，旁邊有傾斜的「找一本書」搜尋貼紙。

## 8. Navigation Pattern
- `top-category-nav`：暖色 Header、左側書本 mark + 「行文書店」襯線 Logo。
- 選單：首頁 / 關於我們 / 選書目錄 / 主題專櫃 / 閱讀專欄；右側「來店地圖 →」深色 CTA。
- 手機版左側 drawer（不是右側），不遮 Logo，展開後文字與背景對比清楚。

## 9. Content Rhythm
- featured-books（書架式選書卡）→ events（讀書會列表）→ blog（選書專題）→ owner（店主推薦）→ testimonials → faq → visit CTA。
- 每個章節都有 eyebrow 小標、襯線 h2 與一段舒適閱讀寬度的說明文字。

## 10. 圖片風格要求
- 全部使用書店 / 閱讀 / 書本類別照片。
- 統一套用 sepia(.15–.2) saturate(.8) contrast(.97) 的暖紙濾鏡。
- 書籍卡以 3:4 封面比例呈現，像站在書架上一樣。

## 11. 圖片數量要求
- 全站至少 25 張圖片引用，分散到不同頁面與章節。
- 每張圖片皆需繁體中文 alt，不可用純裝飾性 icon 代替。
- 來源記錄於 `assets/img/image-sources.md`。

## 12. 12 頁內容定位
1. `index.html` 首頁：知識 Hero、選書、專題、活動、店主、回饋、FAQ、CTA。
2. `about.html` 關於我們：創店故事、三件不變的事、數字、空間。
3. `services.html` 選書目錄：五大類書架清單（category-shelf-list）與新書。
4. `service-detail.html` 書籍詳情：書籍資訊、店員導讀小卡、出版館藏。
5. `portfolio.html` 主題專櫃：八座主題書架（shelf-book-grid）。
6. `reviews.html` 顧客回饋：六則讀者留言與數據。
7. `faq.html` 常見問題：八題手風琴 + FAQPage Schema。
8. `booking.html` 活動報名：活動列表 + 假送出表單。
9. `process.html` 參與流程：四步驟時序 + 小提醒 FAQ。
10. `blog.html` 閱讀專欄：六篇文章卡 + 投稿說明。
11. `blog-detail.html` 文章內容：完整文章、drop cap、引言、Article Schema。
12. `contact.html` 聯絡我們：店鋪資訊、地圖示意、聯絡表單。

## 13. SEO 關鍵字策略
- 核心詞：行文書店、獨立書店、選書、讀書會、閱讀專欄、台北書店。
- 每頁 title 含品牌 + 頁面名；description 60–160 字繁體中文。
- 首頁與聯絡頁 LocalBusiness Schema；文章頁 Article Schema；FAQ 頁 FAQPage；書籍頁 Book。

## 14. CTA 策略
- `article-read-link`：各卡片使用「閱讀全文 →」「閱讀更多 →」「瀏覽 →」文字連結。
- 活動使用「報名活動 →」。
- 全站最後以深色「來店走走 →」band 收尾，形成溫暖而明確的轉換動線。

## 15. RWD 規則
- 桌機 3–4 欄；平板 2 欄；手機 1 欄。
- Hero 在手機改為上圖下文字，書籍照片高度縮至 300px。
- 表單兩欄在手機折為單欄；文章首字放大縮小以避免破版。

## 16. 可替換內容
- 品牌名「行文書店」、地址電話、營業時間。
- 書名、作者、推薦文案、活動場次。
- 店主照片、讀者留言、文章內容與標籤。
- 所有 Unsplash 圖片可替換為客戶授權照片。

## 17. 禁止事項
- 禁止簡體字、中英混雜（專有名詞除外）。
- 禁止深色玻璃質感、霓虹、誇張漸層或亮面現代風。
- 禁止 generator 批次產生頁面，必須逐頁手寫。
- 禁止「建置中 / Coming Soon / 內容待補」；禁止假連結 `#`（社群除外）。

## 18. 與相似樣板的差異說明
- 不同於 template-018 Language School 的明亮藍黃方案導向：本樣板是暖棕紙感與書架分類，沒有價格表與鮮艷色。
- 不同於 template-021 Local Farm 的田園故事長卷軸：本樣板以書架、文章與讀書會為核心，不是農產故事。
- 不同於 template-019 Home Decor 的暖白家居雜誌：本樣板強調紙張觸感、serif 文學性與 marginalia 註記，而非室內空間攝影。
- 獨特的 paper-brown-knowledge-hero、垂直書脊裝飾、手寫推薦小卡與 shelf-book-grid，使其在 24 套中具備至少四項明顯差異。
